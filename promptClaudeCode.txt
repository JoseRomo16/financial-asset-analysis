### src/data_loader.py

### src/metrics.py
Implement all these functions with full docstrings:
- `calcular_retornos(df, metodo)` → arithmetic or logarithmic daily returns
- `calcular_retorno_acumulado(retornos)` → cumulative product
- `calcular_retorno_total(retornos)` → total period return per asset
- `calcular_retorno_anualizado(retornos)` → geometric annualized return (252 trading days)
- `calcular_volatilidad(retornos, ventana, anualizar)` → rolling volatility
- `calcular_volatilidad_total(retornos)` → full-period annualized volatility
- `calcular_drawdown(retornos)` → drawdown from rolling maximum
- `calcular_max_drawdown(retornos)` → maximum drawdown per asset
- `calcular_sharpe(retornos, tasa_libre_riesgo=0.05)` → annualized Sharpe ratio
- `calcular_var(retornos, confianza=0.95)` → historical VaR (positive = loss)
- `resumen_metricas(retornos, tasa_libre_riesgo)` → full summary DataFrame

### src/visualizer.py
Implement these functions, saving outputs to reports/figures/:
Static (matplotlib + seaborn):
- `graficar_precios(df, guardar)` → normalized prices base 100
- `graficar_retorno_acumulado(ret_acum, guardar)` → cumulative returns %
- `graficar_drawdown(drawdown, guardar)` → filled drawdown chart
- `graficar_correlacion(retornos, guardar)` → lower-triangle heatmap
- `graficar_distribucion_retornos(retornos, guardar)` → histogram + KDE per asset

Interactive (plotly):
- `graficar_retorno_interactivo(ret_acum, guardar)` → with range selector buttons (6M, 1A, 3A, Todo) and rangeslider, save as HTML
- `graficar_volatilidad_interactiva(vol, guardar)` → rolling volatility, save as HTML

Color palette: ["#2563EB", "#16A34A", "#DC2626", "#D97706", "#7C3AED"]
